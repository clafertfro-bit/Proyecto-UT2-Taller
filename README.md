# Taller Mecánico

## Descripción del Negocio
Aplicación de consola en C# desarrollada para la gestión integral de un taller mecánico. Permite registrar órdenes de reparación, calcular presupuestos con servicios adicionales, aplicar descuentos por volumen, gestionar modalidades urgentes y llevar el control del balance de caja diaria.

## Instrucciones de Ejecución
1. Asegúrate de tener instalado .NET SDK en tu equipo.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta el comando: dotnet run
